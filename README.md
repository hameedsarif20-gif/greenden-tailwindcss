🌿 Greenden – Week 3 EMC Project

A simple and clean plant-themed website built using HTML and TailwindCSS.
This project showcases my progress in learning TailwindCSS during my 3rd week in the EMC program.

📌 Project Overview

Greenden is a mini multi-page website containing:

Home Page – Hero section, About, Best Sellers, Newsletter, and Footer

Products Page – Grid layout of plant products

Contact Page – Fully styled contact form built with TailwindCSS

Responsive Navigation Bar

Fully responsive design using TailwindCSS utilities
